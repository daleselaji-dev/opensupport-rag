# V0.8 Multimodal

The page-level PDF text baseline is implemented and runnable. The current local
snapshot uses the official CFPB Consumer Response Annual Report 2025 PDF,
producing 96 page evidence records with page metadata and source URL provenance.
Table/chart visual retrieval and region-level citation still require a separate
visual model and page-level Golden Set; the text baseline must not be described
as multimodal visual Recall.
